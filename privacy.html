Privacy policy for ai-workspace-api

Who uses it

ai-workspace-api is a private tool used only by its owner, in his own Google account. It is not offered to anyone else.

What it accesses

  • Email in the owner's Gmail account, read only.
  • Contacts in the owner's Google account, to read and update them.
  • Events in the owner's Google Calendar, to read and update them.

How the data is used

The data is used only to run the owner's own automated tasks, such as sorting his email and keeping his contact cards current. Results are stored in the owner's private storage.

Sharing

The data is processed only by the services the owner uses to run his tasks: GitHub, which runs the tasks and stores the results, and Anthropic's Claude API, which reads text where a task needs judgment. It is not sold, not shared with anyone else and not used for advertising.

Google API Services User Data Policy

The use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The owner can remove the tool's access at any time from his Google account's third-party connections page.
